# Status: autoFRAP NIS-Elements Automation

## Purpose
Automate multi-FOV, multi-cycle FRAP on Nikon microscopes via NIS Elements. Survey → detect → pick cell → create whole-cell + stimulation ROI → run stimulation → save. See `DESIGN_GOALS_AUTOFRAP.md` for the full workflow.

## Current state

**Infrastructure – verified**
* Macro execution: temp `.mac` → `nis_ar.exe -mw` → temp `.ini`. Helper `_run_macro` used by all `nis_util` wrappers.
* Live-verified wrappers: `get_position`, `get_resolution`, `get_rotation_matrix`, `get_optical_confs`, `get_nd_acq_tabs`, `get_opened_documents`/`activate_document`/`activate_opened_document`, `get_roi_ids`, `run_current_nd_experiment`, `run_stimulation_experiment`, `save_current_document`, `add_polygon_roi`, `set_roi_type`, `delete_roi`.
* FOV = xres * pixel_size / magnification. e.g. 133.1 µm at 100x/13 µm.
* **New macro batching pattern** `autofrap/microscope/nis.py`: `MacroOp` dataclass with `build(params,section)` and `parse`. Ops for `position`, `resolution`, `nd_acq_tabs` refactored; `batch_run_macro` runs multiple ops in one `nis_ar` call with unique ini sections. See `docs/NIS_REFERENCE.md` § Macro batching.
* More `MacroOp`s for batching and idempotent cleanup: `checkpoint`, `delete_all_rois_in_current_document`, `close_all_docs`, `set_position`, `set_optical_configuration`, `add_polygon_roi`, `close_current_document`; since 20261002 the whole stimulation step is batched as well: `create_and_set_stim_roi` (polygon ROI + `ChangeROIType(3)` in one op; single-call wrapper `add_polygon_roi_and_set_stim_type`), `run_stimulation_experiment`, `activate_document`, `save_current_document`. `FakeNIS` patched for `batch_run_macro` and all ops. Live-verified 20260918: `delete_all_rois_in_current_document` (backward-iteration delete loop) + `close_current_document`; 20261005: the fully batched stimulation step in a live continuous run (`checkpoint` / `close_all_docs` still not run on the scope).
* Batching gotcha: NIS macro requires all variable declarations before any executable statements. `batch_run_macro` now hoists `int/double/char/dword/byte/word/float` declarations to the top and automatically renames variables to `section_var` to avoid collisions across ops. Every `nis_ar` call carries a roughly constant startup overhead, so batching several ops into one call measurably reduces it (verified live; concrete timings in `docs/SESSION_HISTORY.md`).
* Macro traffic logging + failure evidence (20261008): `_run_macro` DEBUG-logs the macro body, the `nis_ar` stdout/stderr (captured to a temp file instead of discarded) and the ini result of every call; on failure the temp files are preserved — copied to `<run_dir>/macro_debug/` while the pipeline's `macro_debug_dir(run_dir)` context is active, otherwise kept in the OS temp dir — and the location is logged at ERROR.

**Detection**
* `build_detector` composer with `parameter_map=None|dict` (explicit dicts only — `'auto'` was removed 20260929). Runtime args via `--detector-arg`.
* Detector CLIs share contract logic (20261009): `core/detection.py` `unpack_detection_result` (normalize detection_fun output) and `parse_detector_args` (KEY=VALUE → kwargs, int/float coercion) are used by both `python -m autofrap.pipeline` and the offline detector runner `python -m autofrap.detectors` (`autofrap/detectors/cli.py`: runs one detector file on one image, prints per-cell summary + which cell a fresh FOV's first cycle would pick, saves a QC overlay; `--detector-arg`/`--out`/`--verbose`, exit 1 on errors, 0 even with no selectable cell). The five built-in detector files no longer carry per-file `__main__` blocks.
* Remote Cellpose: `cellpose_server.py` FastAPI, `POST /detect` np.save in/out. Client `remote_detect_objects` 60 s timeout + 1 retry.
* Border discard + relabel `distance`/`shuffle`. Stim mask default = left half of object.
* Detector files live in `autofrap/detectors/` (see the directory for the current list; built-ins table in `WRITING_DETECTOR.md`).
* Deprecated import aliases removed 20261001: the `autofrap/core/detection.py` `__getattr__` shim and the `autofrap/core/simple_seg.py` shim are gone — import building blocks from `autofrap.core.image.segmentation` / `autofrap.core.image.mask` / `autofrap.core.image.qc` directly.

**Pipeline**
* Entry point `autofrap()` (setup + position build) → `autofrap_loop_outer()` over positions → `autofrap_loop_inner()` per FOV (the original `autofrap()`). The old `autofrap_grid` / `autofrap_multiposition` aliases and the `__init__.py` re-exports were removed (20261001) — import from `autofrap.pipeline.autofrap`; `autofrap/__init__.py` and `autofrap/pipeline/__init__.py` are empty. Position helpers live in `autofrap.core.utils.grid` (`grid_positions`; `spiral_positions` — generator-based since 20261001, signature `(position, fov, max_positions, spacing=1.0)` with `fov=(fov_x, fov_y)`), cell selection `select_next_cell` in `autofrap.core.image.mask` (since 20261009: candidate order + polygon viability in one helper, shared with the detector runner).
* Stage moves are verified after the fact: `move_stage_with_retry` batches set+get position and retries on timeout or >1 µm deviation (20261002).
* The pipeline no longer accumulates/returns per-FOV results lists; the grid summary is logged from counters (20261002). CLI exposes `--allow-interrupt-after-survey` (opt-in stop after survey + detection, 20261001).
* CLI entry point (20261008): `--help` groups the options via `add_argument_group` (detection, output, microscope/acquisition, stage positions, cycles per FOV, run behavior, logging). Default visit order is now the centre-out spiral: `--max-positions` defaults to 25 (start + two loops, `SPIRAL_DEFAULT_POSITIONS` in `autofrap/pipeline/autofrap.py`); `--grid` opts into the plain NxM grid instead (`--nx/--ny` are grid-mode-only, the spiral count comes solely from `--max-positions`). Library defaults flipped to match: `autofrap()`/`build_positions()` now default to `spiral=True` (`spiral=False` selects the grid). Run-summary log lines say `run:`/`Run done:`/`Run stopped by user:` (not "grid").
* Logging (20261008): the pipeline logs via a module logger — INFO milestones (grid/FOV headers, per-cycle heartbeat, summaries), WARNING for recoverable FOV failures, ERROR for aborts, DEBUG for detail (ROI ids, polygon sizes, stage target vs. actual, cleanup counts). The CLI configures logging: INFO by default, `--verbose` for DEBUG; library callers call `logging.basicConfig()` themselves. While a grid run is active, failed macro temp files are preserved in `<run_dir>/macro_debug/`.
* Cross-cycle cell tracking: `match_imaged_centroids` (`autofrap/core/image/mask.py`) against an accumulated “already imaged” map (`centroid_threshold='auto'` ≈ one equivalent diameter per cell), so each cell is stimulated at most once.
* Run dir naming: `<out>/<stamp>_<name>` with `--name`/`--no-timestamp`. Non-empty dir collision aborts.
* Error handling: any FOV-level failure skips the FOV; the grid aborts after `--max-consecutive-failures` (default 3) consecutive FOV failures (a completed FOV resets the counter). `AbortRunError` (configuration/resource) aborts immediately. Best-effort per-cycle cleanup. Full policy + the timeout assumption: `autofrap/pipeline/autofrap.py` module docstring.
* Clean Ctrl-C: `AutofrapInterruptedException` with checkpoints P1 cycle end, P2 after survey, P3 between FOVs.
* Live verified 20260901: 2×2 grid, real DAPI nuclei, cellpose `diameter=70`. Survey ~10 s, detection ~2.1 s, stimulation ~14 s, return to start. Live verified 20261005: continuous run with the fully batched stimulation step.
* FakeNIS offline dry-run works: `autofrap/microscope/fake_nis.py` (failure table for error injection) + `autofrap/autofrap_bitsnpieces/dry_run_pipeline.py` (thin wrapper around the real CLI) + `tests/pipeline/test_offline_pipeline.py` (offline suite: fake sanity, pre-flight, failure policy, clean stop).
* **Tests** – stdlib `unittest` suite in `tests/` (mirrors the package layout; `tests/live/` needs the microscope and auto-skips elsewhere, data-dependent tests skip when their files are missing). Run from the repo root: `python -m unittest discover -s tests -t .` (plain `python -m unittest discover` works too). Currently 117 tests, 10 skipped on a machine without `01.nd2` / off-scope.

**QC**
* `autofrap.core.image.qc.save_qc_overlay` renders per-cycle PNG with image, FRAP mask, labels, polygons, legend. Also saved when no cell is selectable (all stimulated / no FRAP-mask overlap / no viable polygon): overlay without the cell/ROI polygons, caption `no cell (...)` — diagnoses "truly empty FOV" vs. "detector too conservative" (20261009).

## Known gotchas

* FakeNIS patching works by modifying the module object (`autofrap.microscope.nis`), not by name matching. Direct function imports (`from module import function`) create independent references that bypass patching. Always access NIS operations via the module namespace (e.g., `nis_util.batch_run_macro()`, `nis_util.OP_MACRO_NAME`) to ensure FakeNIS can patch them.
* ROIs are session-global (`ScopeType.Global`) and picked up by any new acquisition — the pipeline deletes all ROIs before/after each cycle via `cleanup_everything` (details: `docs/NIS_REFERENCE.md` § Important ROI behavior).
* Other NIS-specific gotchas (macro file handles, `Int_SetKeyValue`, absolute paths, `CloseCurrentDocument` dialog, `ND_DefineExperiment` save switch, `Frozen` live view, ...): `docs/NIS_REFERENCE.md` § Gotchas.
